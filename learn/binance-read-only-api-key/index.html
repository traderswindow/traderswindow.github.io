How to create a read-only Binance API key, and keep it safe

Many portfolio and trading tools ask for a Binance API key. A read-only key lets them see your balances and positions without being able to trade or withdraw.

What an API key is

An API key lets a program talk to your Binance account without your password. It comes in two parts: the API key, like a username, and the secret key, like a password. Each key has its own permissions, and a key with reading only can look but not touch.

Creating the key

  1. Log in to Binance on the web, click your profile icon and open API Management.
  2. Click Create API and choose the system-generated key type.
  3. Give it a label you'll recognize later, for example the name of the app that will use it.
  4. Complete the security verification (2FA, email or passkey).
  5. Copy the API key and the secret key right away. Binance shows the secret only once.
  6. Click Edit restrictions and check the permissions. Leave only Enable Reading on.

Binance changes its screens from time to time, so labels may differ slightly. Its own guide is How to create API keys on Binance.

Permissions to leave off

  • Spot & Margin Trading: lets the key place and cancel orders.
  • Futures: lets the key trade futures. Reading your futures positions doesn't need it.
  • Withdrawals: lets the key move funds out. Never enable it for a tool that only displays data.
  • Universal Transfer, margin loans and similar options: not needed to read.

An IP restriction adds protection if your internet connection has a fixed IP address. Most home connections don't, so read-only keys are commonly left unrestricted.

Keeping it safe

  • Never paste the secret into a chat, an email, a screenshot or a website form you don't trust.
  • Use a separate key for each app, so you can revoke one without breaking the others.
  • Delete keys you no longer use.
  • If you think a secret has leaked, delete the key in API Management right away and create a new one.

Using it with Traders Window

In Settings → Account, paste the API key and secret. The app asks Binance which permissions the key has and refuses it if any trading, withdrawal or transfer permission is on. The key is stored in your Mac's Keychain and used only to talk to Binance directly. With it connected, the widget shows your futures positions, distance to liquidation and today's result against your daily limit.

If your positions don't show up, make sure your Futures account is activated, and try creating a new key after activating it.
